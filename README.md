* AI Resume ATS System

This is an AI-powered Resume ATS (Applicant Tracking System) that evaluates resumes against job descriptions.

* Features
- Resume scoring based on job description
- FastAPI backend
- Simple frontend UI (HTML, CSS, JavaScript)
- REST API integration

** Tech Stack
- Python (FastAPI)
- HTML, CSS, JavaScript
- PostgreSQL (Database)

# How to Run
## frontend
Open frontend/index.html using Live Server

## Backend
```bash
uvicorn app.main:app --reload
